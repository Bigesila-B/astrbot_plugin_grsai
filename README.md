# astrbot_plugin_grsai

AstrBot 插件 —— 调用 Grsai API 实现 GPT 图像生成与图像编辑。

## 功能

- **GPT生图**（文生图）：发送 `GPT生图 提示词` 即可生成图片
- **GPT改图**（图生图）：发送 `GPT改图 提示词` 并附带图片进行编辑

支持 @机器人 或直接使用触发词。

## 配置

在 AstrBot WebUI 的「配置」页面中设置：

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| url | API 基础 URL | `https://grsaiapi.com` |
| apikey | API Key | 空 |
| model | 模型（gpt-image-2 / gpt-image-2-vip） | `gpt-image-2` |
| aspect_ratio | 图片比例/分辨率 | `1:1` |
| pixel_size_mode | 是否把比例自动转换为具体像素值 | `false` |
| reply_type | 回复模式（json / async） | `json` |

API Key 请在 https://grsai.ai/zh/dashboard/api-keys 获取。

## 新版模型尺寸兼容

部分新版模型或 API 节点不再接受 `1:1`、`16:9` 这类比例字符串，而要求 `1024x1024`、`1280x720` 等具体像素值。此时在对应模型配置中开启 **比例转像素模式**（`pixel_size_mode`）：

- `1K`：例如 `1:1` → `1024x1024`，`16:9` → `1280x720`
- `2K`：例如 `1:1` → `2048x2048`，`16:9` → `2560x1440`
- `4K`：例如 `1:1` → `2880x2880`，`16:9` → `3840x2160`
- 用户直接输入 `1024x1024` 等像素值时始终原样传递。

关闭时保持原有行为，比例字符串直接发送给 API，适合仍支持比例参数的旧节点。

## 依赖

- aiohttp >= 3.8.0

## 用法示例

```
GPT生图 一只可爱的边牧在草地上奔跑
GPT改图 把这张图片变成油画风格  [附带图片]
```
